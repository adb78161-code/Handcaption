HandCaption V15 — Liquid Glass 2.0

UI/UX polish release based on V14.

Highlights:
- Glass dashboard metrics for packs/projects
- Focus mode for distraction-free editing
- Quick navigation command palette (Ctrl/Cmd+K on desktop)
- Editor grid overlay
- Editor zoom controls
- Sticky glass editor action bar
- Mobile-friendly glass controls
- Existing V14 handwriting, packs, projects, photo/video captioning and local processing retained.

Deploy by replacing index.html, style.css and app.js in the GitHub Pages repository. Keep index.html at the root of the configured publishing source.
